# OOP Exercises

A collection of Python small projects created to practice **Object-Oriented Programming (OOP)** and software engineering principles.

The repository is continuously being developed as I learn new concepts and improve the structure and quality of the exercises.

## 🎯 Goals

* Strengthen my understanding of Object-Oriented Programming in Python.
* Practice designing and working with classes and objects.
* Improve code organization and maintainability.
* Gradually apply more professional software engineering practices.

## 📚 Topics

The exercises cover concepts such as:

* Classes and Objects
* Constructors
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Abstract Classes and Methods
* Composition
* Exception Handling
* Testing
* Project Structure

More concepts and exercises will be added as the project progresses.

## 🛠️ Technologies

* Python
* pytest
* Git / GitHub

## 📈 Progress

This repository is a learning project and is **actively being developed**.

The structure and implementation of the exercises will continue to evolve as I gain more experience with OOP.
